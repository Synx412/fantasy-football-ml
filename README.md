# Fantasy XI Ensemble ML v5

A free Streamlit fantasy-football research app for:

- Premier League
- La Liga
- Bundesliga
- Serie A
- Ligue 1
- UEFA Champions League

It predicts points, starts, appearances and minutes for upcoming fixtures, estimates uncertainty and non-official prices, then selects a valid 15-player squad and starting XI.

> This project is for free fantasy analysis only. It does not use betting odds and is not intended for betting or paid-entry contests.

## What changed in v5

### Global starter-probability correction

The availability layer now uses **team matches played** as the main denominator for the historical start prior instead of treating a player's own appearances as the denominator. This is applied to every player, so rotation players cannot become near-certain starters simply because they have a small appearance sample.

There are no player-specific patches. Marmoush/Gabriel Jesus-style errors are handled by the same global logic used for everyone.

### Lineup intelligence

The app now supports three availability evidence layers on top of the ML model:

1. **Recent actual lineups** generated by `scripts/fetch_recent_lineup_history.py` using `soccerdata`/FBref.
2. **Predicted-lineup consensus CSVs**, either one vote per source or an already aggregated probability.
3. **Confirmed API-Football lineups near kickoff**, which override predictions for the next fixture when available.

The model keeps later fixtures in a multi-match horizon predictive rather than incorrectly carrying a confirmed lineup into future matches.

Default squad filtering remains **60% minimum start probability**, and the default uncertainty penalty is **0.30**.

See `V5_CHANGES.md` for the full implementation notes.

## Core v4 ensemble retained

### Real ML ensemble

The pre-trained model now combines two different gradient-boosting families:

- scikit-learn `HistGradientBoostingClassifier/Regressor`
- XGBoost `XGBClassifier/XGBRegressor`

They are blended instead of relying on a single model. The supplied time-ordered holdout benchmark is approximately:

- Points MAE: **1.38**
- Start Brier score: **0.092**
- Appearance Brier score: **0.090**
- Minutes MAE: **14.3 minutes**

The exact metrics can change if you rebuild the training table or train on custom history.

### Multitask prediction

The model separately estimates:

- probability of starting
- probability of appearing
- expected minutes
- expected fantasy points
- P10 / P90 point range
- projection confidence

Expected points also use position-specific starter/substitute models, but direct point prediction is weighted more heavily because it validated better on the included season.

### Public-data enrichment

`scripts/fetch_public_soccer_data.py` can fetch free public player statistics through the open-source `soccerdata` package and save them to:

```text
data/public_player_enrichment.csv
```

The Streamlit app can upload that CSV as **Optional public-stat enrichment CSV**. It can fill season totals such as minutes, starts, goals, assists, xG and xA while leaving live fixtures, prices and availability under the live providers.

Use public scrapers responsibly and follow each source's terms and rate limits.

### Google Colab training

A ready-to-run notebook is included:

```text
notebooks/train_in_colab.ipynb
```

It installs the free Python stack, optionally trains XGBoost on a Colab GPU, rebuilds the model artifact, runs the smoke tests, and lets you download the trained `joblib` file. Before the model is saved, XGBoost is switched back to CPU inference so the artifact remains portable to Streamlit Community Cloud.

## Included training data

The bundled supervised history contains:

- 27,605 raw 2024/25 FPL player-fixture rows
- 16,359 leakage-controlled next-fixture training rows
- next-fixture points labels
- start labels
- appearance labels
- minutes labels

`scripts/build_multitask_history.py` reproduces the multitask table. Rolling information is shifted before the target fixture, and the potentially leaky FPL `xP` field is excluded.

## Live data

### Premier League

Official FPL public endpoints provide player prices, form, points, xG, xA, bonus/BPS, availability, fixtures and difficulty. No key is needed.

### Other competitions

API-Football provides player season statistics and injuries. `football-data.org` is an optional second source for fixtures, results and team context. If the secondary source is unavailable, fixtures fall back to API-Football.

Only one competition is loaded at a time. Player pages are cached for six hours, injuries for 15 minutes and fixtures for 30–60 minutes to protect free quotas.

## Prices outside FPL

There is no single official fantasy-price feed across every supported competition. Missing values are predicted by a separate ML model and labelled:

```text
ML-estimated price — not official
```

For exact budget compliance, upload a CSV:

```csv
name,price
Player One,7.5
Player Two,10.0
```

## Install locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Premier League and Demo mode work without keys. For the other live competitions, create `.streamlit/secrets.toml`:

```toml
API_FOOTBALL_KEY = "your_api_football_key"
FOOTBALL_DATA_TOKEN = "your_optional_football_data_org_token"
```

You can also paste keys into the sidebar or use environment variables with the same names.

## Install the training/scraping stack

For VS Code, Jupyter or a local training machine:

```bash
python -m pip install -r requirements-training.txt
```

This adds `soccerdata`, JupyterLab and the training dependencies on top of the deployed app stack.

## Fetch free public soccer statistics

Example:

```bash
python scripts/fetch_public_soccer_data.py \
  --season 2025-26 \
  --leagues epl,laliga,bundesliga,serie-a,ligue-1 \
  --output data/public_player_enrichment.csv
```

The script uses association-football sources. `nflverse` and `nfl_data_py` are for American football, so they are not appropriate for this soccer model.

## Fetch recent actual lineups

```bash
python scripts/fetch_recent_lineup_history.py \
  --season 2026-27 \
  --matches-per-team 6 \
  --output data/recent_lineup_history.csv
```

Upload the generated CSV under **Optional recent actual-lineup history CSV**. This gives recent manager selections more weight for every matched player.

For predicted-lineup source votes, use `data/lineup_intelligence_template.csv` or upload an aggregated file with `name,club,start_probability,source_count`.

## Rebuild and retrain

```bash
python scripts/build_multitask_history.py
python scripts/build_pretrained_bundle.py
python tests/smoke_test.py
```

To train XGBoost on a CUDA-enabled machine or Colab runtime:

```bash
FANTASY_XGB_DEVICE=cuda python scripts/build_pretrained_bundle.py
```

The saved deployment artifact is automatically switched back to CPU inference.

## Accuracy boundaries

- Football has genuine rotation, injury and tactical uncertainty; no model can guarantee the highest-scoring team.
- The bundled labels are Premier League history. Other competitions still use transfer learning unless you provide competition-specific labelled history.
- Public season statistics improve feature coverage, but they do not replace confirmed team news or a competition-specific fantasy scoring dataset.
- Official fantasy formats may use different scoring rules. The supplied roster shape is 2 GK, 5 DEF, 5 MID and 3 FWD.
- Estimated non-FPL prices are not official prices.

## Data attribution

Historical FPL data is derived from the open Vaastav Anand Fantasy-Premier-League dataset. Review the upstream documentation and licence before redistributing raw data separately.
